# Frameworks: from historical ideas to modern workflows

This file explains how the project's models are derived and where interpretation begins.

## 1. 过渡时代 → Transition diagnosis

**Historical anchor:** 《过渡时代论》 distinguishes periods of relative stability from periods of transition and treats transition as a recurring feature of social development.

**Modern transfer:** In product, career and organizational analysis, first determine whether failure comes from poor execution inside a stable game or from the game itself changing.

**Questions**

- Which constraints changed in the last 12–36 months?
- Which assumptions used to be true but are no longer reliably true?
- Which changes are irreversible or compounding?
- What evidence would show that the apparent transition is only noise?

**Failure mode:** calling every trend a “new era”.

---

## 2. 新民 → Capability before mechanism

**Historical anchor:** 《新民说》 argues that institutional and national renewal cannot be separated from the qualities and capacities of the people who constitute the system.

**Modern transfer:** A new process, incentive system or organizational chart fails if people lack the skills, information, autonomy or habits required to operate it.

**Diagnostic layers**

1. Individual capability
2. Team coordination
3. Organizational mechanisms
4. External environment

**Failure mode:** blaming “people quality” for structural problems. Always inspect incentives and information flow too.

---

## 3. 淬厉本有 / 采补本无 → Preserve and acquire

**Historical anchor:** In 《新民说》, “new” does not simply mean discarding the old; it includes strengthening what is already valuable and acquiring what is absent.

**Modern transfer:** Transformation should create four lists:

- Preserve & strengthen
- Acquire & learn
- Stop & unlearn
- Do not copy

**Failure mode:** either nostalgic protectionism or total imitation.

---

## 4. 今日之我 → Evidence-triggered belief revision

**Historical anchor:** In 《清代学术概论》 Liang describes his willingness to challenge his earlier self: “不惜以今日之我，难昔日之我”.

**Modern transfer:** Belief revision needs triggers, not mood.

A major belief should be reconsidered when:

- a core premise becomes false;
- new evidence has higher quality than the evidence behind the old view;
- repeated outcomes contradict the model;
- environment changes invalidate the old optimization target;
- a simpler model explains more with fewer exceptions.

**Failure mode:** confusing adaptability with inconsistency.

---

## 5. 学术变迁 / 比较 → Compare conditions, not labels

**Historical anchors:** 《论中国学术思想变迁之大势》《清代学术概论》《中国近三百年学术史》.

**Modern transfer:** Before learning from another company, country, historical period or discipline, align conditions.

Minimum comparison matrix:

| Dimension | A | B | Transfer implication |
|---|---|---|---|
| Stage | | | |
| Resources | | | |
| Constraints | | | |
| Incentives | | | |
| Technology | | | |
| Capabilities | | | |
| Time horizon | | | |

**Failure mode:** analogy as proof.

---

## 6. 史料方法 + 趣味主义 → Evidence discipline and learning energy

**Historical anchors:** 《中国历史研究法》 and Liang's later academic work emphasize historical materials and methods; 《学问之趣味》《敬业与乐业》 provide a separate line on sustained engagement with work and learning.

**Modern transfer:** High-quality research needs both rigor and persistence. Rigor without interest becomes brittle; interest without evidence becomes story-telling.

**Evidence labels**

- P1: primary source / original data
- P2: near-primary record / authoritative archive
- S1: high-quality scholarly synthesis
- S2: reputable secondary analysis
- U: unverified / user report / anecdote

**Failure mode:** “I found many sources” mistaken for “the sources independently confirm the claim”.
