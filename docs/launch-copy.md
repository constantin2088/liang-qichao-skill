## GitHub Release v1.0.0

### 梁启超·自新与变局 Skill 首发

我做了一个梁启超相关的 Agent Skill，但它不是“梁启超聊天角色”。

我更感兴趣的问题是：**当旧经验开始失效时，我们到底应该怎么更新自己？**

这个 Skill 把梁启超著述中关于过渡时代、新民、自我修正、比较、史料与学习趣味的线索，重新组织成一套现代工作流：

> 判变局 → 盘本有 → 补本无 → 难旧我 → 做比较 → 核史料 → 落试验

它主要用于：

- AI / 行业变化下的职业转型；
- 旧组织面对新业务时的制度更新；
- 新证据出现后的认知修正；
- 跨公司 / 跨制度 / 跨时代比较；
- 研究中的史料分层与反证；
- 把“学很多”变成真正的新能力。

项目坚持三个边界：不伪造梁启超引语；不让历史人物评价其身后事件；不把历史思想包装成现代万能公式。

安装：

```bash
npx skills add constantin2088/liang-qichao-skill
```

欢迎用一个你正在经历的真实“变局”来测试它，也欢迎直接提交反例。

## 社交平台短版

我把梁启超做成了一个 Agent Skill。

但不是“让 AI 模仿梁启超说话”。

我想做的是另一件事：把“面对变局时如何更新自己”变成一个可执行工作流。

它会先判断：

- 是你执行得不够好，还是“局”已经变了？
- 过去的优势里，什么还值钱？
- 新环境真正缺什么能力？
- 哪个旧判断最应该被新证据挑战？
- 别人的成功经验，条件真的和你一样吗？
- 能不能用 30–90 天低成本实验先验证，而不是先做不可逆决定？

项目：`liang-qichao-skill`

一句话定位：**在旧经验开始失效时，先判断“局”变了没有，再决定自己该怎么变。**

## 极短版

不是梁启超 Persona。

## 首发 Demo 推荐

首发优先使用“AI 时代的职业转型”案例，因为它：

1. 不需要用户懂梁启超；
2. 能立刻体现“本有 / 本无”；
3. 和当下 Agent / AI 用户的真实焦虑直接相关；
4. 结尾能落到一个可验证的 60 天实验，而不是历史人物语气模仿。
