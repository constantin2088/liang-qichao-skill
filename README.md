# 梁启超·自新与变局 Skill

### 在旧经验开始失效时，先判断“局”变了没有，再决定自己该怎么变。

**一个面向 Codex / Claude Code / Cursor / Agent Skills 的中文 thinker skill。**  
不是梁启超角色扮演，不是语录生成器，而是一套用于 **职业转型、组织变革、认知更新、比较研究与持续学习** 的可执行方法。

## 30 秒看效果

### 例 1：AI 时代，我十年的经验是不是要归零？

> **用户**：我在传统制造业做了十年供应链。AI 很火，我担心继续做会被淘汰，但彻底转 AI 又像从零开始。怎么办？

**Skill 不会先劝你“拥抱变化”。它先拆：**

- **正在变**：信息处理速度、自动化范围、数据能力要求。
- **没有变**：行业知识、供应商关系、真实产能、质量责任、跨部门协调。
- **淬厉本有**：十年供应链判断、异常处理、成本结构理解。
- **采补本无**：数据分析、AI 工具编排、流程自动化、知识沉淀。
- **最该挑战的旧假设**：“转型 = 离开原行业。”
- **先做的实验**：用 60 天把一个高频供应链流程 AI 化，用节省时间、错误率、采用率和决策质量验证价值，再决定是否扩大转型。

→ [完整案例](examples/career-transition.md)

### 例 2：领导说“扁平化”，真的能解决审批慢吗？

Skill 会先判断：这是**执行慢**，还是**旧业务的控制方式已经不适合新业务**？

然后保留重大风险阈值与责任留痕，引入分层授权、例外管理与实时数据，而不是把“扁平化”这个标签当答案。

→ [完整案例](examples/org-change.md)

### 例 3：新材料和我的论文结论冲突，要不要推倒重来？

Skill 会启动“**今日之我审计**”：区分新材料是在推翻事实、因果解释，还是只增加边界条件；先写一页最强反方 memo，再用第三组独立证据决定是局部修订、模型升级还是核心反转。

→ [完整案例](examples/research-reframe.md)

## 它解决什么问题

你可能遇到的不是“做得不够好”，而是**旧问题已经变成了新问题**：

- AI、行业周期或监管环境变化后，过去的经验还值多少？
- 公司旧流程越来越慢，是执行差，还是游戏规则已经变了？
- 一个曾经正确的判断，现在要不要推翻？
- 别人的成功方法，哪些能学，哪些不能照搬？
- 面对大量材料，怎样区分事实、解释、类比和猜测？
- 为什么收藏了很多知识，却没有形成真正的新能力？

核心工作流：

> **判变局 → 盘本有 → 补本无 → 难旧我 → 做比较 → 核史料 → 落试验**

它追求的不是“像梁启超说话”，而是把一组历史上可辨认的方法线索，转成现代 AI Agent 可以稳定执行的分析程序。

## 六个核心模型

| 模型 | 先问什么 | 现代用法 |
|---|---|---|
| **过渡时代** | 是旧系统执行差，还是外部规则正在变化？ | 区分结构变化与短期噪声 |
| **新民** | 新制度需要的新能力真的存在吗？ | 检查技能、责任、协作、自治与信息机制 |
| **本有 × 本无** | 什么该守，什么该补，什么该停？ | 同时强化已有优势、补齐新环境所需能力 |
| **今日之我** | 什么证据足以让我修改旧判断？ | 把“改口”变成有纪律的认知更新 |
| **比较与思潮** | 两个对象的阶段、资源和约束真的可比吗？ | 迁移原则，不机械复制结论 |
| **史料与趣味** | 证据够不够真？学习能不能持续？ | 证据分层、反证、输出驱动学习 |

详细推导见 [references/frameworks.md](references/frameworks.md)。

## 它不是什么

### 不是“梁启超 GPT”

默认不模仿历史人物口吻。只有用户明确要求风格化表达时，才会使用更强的设问、对照、排比和时代感，并明确标注为**现代拟写，不是梁启超原文**。

### 不是名言拼接器

无法回溯到可靠文本的“名言”不会进入核心规则。直接引语优先查一手文本；不能确认时只做释义，不加引号。

### 不是万能战略框架

“过渡时代”“新民”“本有 / 本无”等都是**现代产品化抽象**。它们用于组织问题，不是把历史概念强套到所有现代场景。

### 不是高风险专业建议替代品

医疗、法律、财务等高风险问题需要相应专业支持；本 Skill 不能替代专业判断。

## 为什么是梁启超

这个项目选择梁启超，不是因为他“说过很多名言”，而是因为他的著述中反复出现几条特别适合转成 Agent 工作流的线索：

- 《过渡时代论》提供了“稳定期 / 过渡期”的观察入口；
- 《新民说》把制度变化和人的能力更新放到同一问题中；
- “淬厉其所本有、采补其所本无”提供了一种避免全盘否定与全盘照搬的更新方式；
- 《清代学术概论》中的自我修正意识，为“今日之我审计”提供历史锚点；
- 晚年的史学和学术史写作，为比较、证据与材料意识提供方法来源；
- 《学问之趣味》《敬业与乐业》则补上长期学习与持续投入这一层。

项目不主张把这些历史判断直接搬到今天，而是做**有边界的现代转译**。出处与解释层级见 [references/sources.md](references/sources.md) 与 [NOTICE.md](NOTICE.md)。

---

## 设计原则

1. **先判是否变局，再优化旧系统。**
2. **能力更新与制度更新分开检查。**
3. **既不守旧，也不崇新：本有要淬厉，本无要采补。**
4. **允许新证据推翻旧自己，但必须留下修改理由。**
5. **比较条件，不把类比当证据。**
6. **历史事实、梁启超原意、项目解释、现代转译四层分开。**
7. **最后必须落到可验证的短周期行动。**

## 资料边界

项目遵守四条硬规则：

1. **不伪造引语。** 无法核实的网络名言不进入核心规则。
2. **不替历史人物评价身后事件。** 梁启超 1929 年去世；现代问题只能做方法迁移。
3. **不把思想变化抹平。** 早年政治活动、中期公共思想与晚年学术工作的侧重点并不完全相同。
4. **不把历史思想包装成现代万能公式。** 每个模型都必须接受现实条件和反证检查。

更详细的资料地图见 [references/sources.md](references/sources.md)。

## 评测

仓库自带基础行为评测：

- 职业转型：是否区分趋势与噪声；
- 组织变革：是否避免把流行管理词当答案；
- 认知更新：是否说明为什么改判；
- 历史研究：是否拒绝未核实引语；
- 身后事件：是否避免伪造历史人物观点；
- 风格模仿：是否明确“现代拟写”；
- 高风险问题：是否知道什么时候停止使用该框架。

## English summary

**Liang Qichao: Renewal & Transition** is a Chinese-language reasoning skill for AI agents. It turns historical ideas associated with Liang Qichao—transition diagnosis, capability renewal, preserve-and-acquire thinking, evidence-triggered belief revision, comparative reasoning, and evidence discipline—into a modern workflow for career change, organizational transformation, research, and strategic learning.

It is **not** a historical-persona roleplay package and does not present generated modern answers as Liang Qichao's actual views.
